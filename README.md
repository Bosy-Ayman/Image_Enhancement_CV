
## 🔍 Project Tasks

### [1] Component Extraction  
**Images:** Circle, COVID-19 Chart  
**Techniques Used:**  
- Canny Edge Detection  
- Hough Circle Transform  
- Morphological Operations

### [2] Enhancement of Blurry Images  
**Images:** Buildings, Dog  
**Techniques Used:**  
- Wiener Filter  
- Unsharp Masking  
- Laplacian Sharpening

### [3] Noise Removal  
**Images:** Text, Rocket, Wind Chart  
**Techniques Used:**  
- Median Filtering  
- Bilateral Filtering  
- Non-Local Means Denoising

### [4] Visual Enhancement of Challenging Images  
**Images:** Newspaper, Name Plate  
**Techniques Used:**  
- CLAHE (Contrast Limited Adaptive Histogram Equalization)  
- Gamma Correction  
- Thresholding + Morphological Filters

## 📄 Deliverables

- ✅ **Original Images**: Provided in `original_images/`  
- ✅ **Processed Images**: Results saved in `processed_images/`  
- ✅ **Python Code**: Jupyter notebooks with full implementation  
- ✅ **Report**: Detailed markdown reports explaining:
  - Techniques used and justification
  - Code implementation
  - Output results and analysis
  - Discussion (pros, cons, quality, limitations, and suggestions)

This project demonstrates the power of classical image processing techniques in improving image quality. The challenges in each image type guided the choice of technique. Each result is discussed in the respective markdown reports.
